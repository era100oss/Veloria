# Полный и понятный разбор плагина **ai-text-plugin** для Perchance  
(На основе полного исходного кода, который ты прислал)

Это плагин для генерации текста с помощью ИИ прямо в твоём генераторе Perchance. Он работает на серверах perchance.org (не локально), поэтому мощный и бесплатный (за счёт рекламы для неавторизованных пользователей).

### Как подключить
В Lists редакторе напиши:
```
ai = {import:ai-text-plugin}
```
Готово! Теперь можно использовать `[ai(...)]`.

### Основной способ использования (простой)
Ты передаёшь объекту свойства — и получаешь текст от ИИ.

Пример из твоего кода:
```
poemPrompt
  instruction = Write a haiku about a [character] in [place] during [season].

output
  [ai(poemPrompt)]
```
ИИ получит инструкцию и напишет хайку.

Можно передать просто строку:
```
[ai("Напиши шутку про программиста")]
```

### Что делает плагин под капотом (пошагово)

1. **Создаёт скрытый iframe**  
   При первом использовании создаётся невидимый iframe с адресом `https://text-generation.perchance.org/embed`.  
   Этот iframe — "мостик" к серверу ИИ. Всё общение идёт через него с помощью `postMessage`.

2. **Проверяет авторизацию**  
   Отправляет сообщение `verifyUser`. Если нужно — показывает индикатор проверки.

3. **Получает твои параметры**  
   - `instruction` — главная инструкция ИИ (обязательно)
   - `startWith` — текст, с которого ИИ обязан начать ответ
   - `stopSequences` — массив строк: если ИИ напишет одну из них — сразу остановится
   - `hideStartWith = true` — скрыть `startWith` в выводе (полезно для чатов)
   - `style` — CSS для контейнера с текстом
   - `outputTo` — элемент (по ID), куда выводить текст вместо обычного места
   - `render(data)` — функция для обработки текста перед выводом (например, *текст* → <i>текст</i>)
   - `onChunk(data)` — вызывается после каждого чанка (слова/части слова)
   - `onStart()` и `onFinish(data)` — колбэки начала и конца генерации
   - `endButtons = none` — убрать кнопки "продолжить" и "редактировать"

4. **Запускает потоковую генерацию**  
   Отправляет в iframe запрос на `/api/generate` с параметрами.  
   Сервер отвечает чанками (кусочками текста) через `postMessage`.

5. **Обрабатывает чанки**  
   - Собирает текст в реальном времени
   - Показывает анимированные точки загрузки (⋯)
   - Обновляет `onFinishPromise.liveResponseText` — текущий текст (можно читать в любой момент)
   - Если включён `render` — пропускает каждый чанк через твою функцию
   - По окончании вызывает `onFinish`

6. **Добавляет кнопки в конце ответа**  
   - ▶️ Продолжить генерацию
   - ✏️ Редактировать текст (открывает textarea поверх, можно изменить и сохранить)

### Что возвращает [ai(...)] или await ai(...)

Это **Promise**, который:
- При использовании в `[ ]` автоматически превращается в HTML-контейнер с текстом и загрузкой
- При `await` даёт объект со свойствами:

| Свойство               | Что содержит |
|------------------------|--------------|
| `text`                 | Полный текст (включая `startWith`) |
| `generatedText`        | Только то, что сгенерировал ИИ (без `startWith`) |
| `liveResponseText`     | Текущий текст (обновляется в реальном времени + учитывает правки пользователя) |
| `inputs`               | Исходные параметры (`instruction`, `startWith`, `stopSequences`) |
| `stop()`               | Функция для принудительной остановки генерации |
| `loadingIndicatorHtml` | HTML с анимированными точками (можно вставить вручную) |
| `submitUserRating({score, reason})` | Отправить оценку ответу (0–1) |

### Продвинутые примеры

**Чат с ИИ-персонажем**
```
chatPrompt
  instruction = Ты — дерзкий пират по имени Джек. Отвечай в стиле пирата.
  startWith = Пират Джек: 
  hideStartWith = true
  stopSequences = [Пользователь:, Ты:]

output
  <div id="chat">[ai(chatPrompt)]</div>
  <input id="userInput" placeholder="Твоё сообщение">
  <button onclick="send()">Отправить</button>

<script>
async send() =>
  let msg = userInput.value
  chat.innerHTML += `<br><b>Ты:</b> ${msg}<br>`
  let result = await ai({
    instruction: chatPrompt.instruction,
    startWith: `${chat.innerHTML}\nТы: ${msg}\nПират Джек: `,
    hideStartWith: true,
    outputTo: chat
  })
  userInput.value = ""
</script>
```

**Текст с форматированием (курсив/жирный)**
```
formatPrompt
  instruction = Напиши историю про дракона.
  render(data) =>
    let text = data.text
    text = text.replace(/\*([^ *]+)\*/g, "<i>$1</i>")   // *курсив*
    text = text.replace(/\*\*([^ *]+)\*\*/g, "<b>$1</b>") // **жирный**
    return text

output
  [ai(formatPrompt)]
```

### Полезные фичи из кода, о которых мало кто знает

- `preload = true` — заранее прогружает модель (ускоряет первый запрос)
- `getMetaObject = true` — возвращает объект с `countTokens(text)` и `idealMaxContextTokens` (полезно для подсчёта токенов)
- Кнопка редактирования позволяет пользователю править ответ и продолжать с новым текстом
