### 1. Основы: Что такое Perchance и как работает редактор списков

Perchance — это инструмент для создания случайных генераторов текста (например, имён, описаний, историй). Всё строится вокруг **списков** (lists): вы определяете списки элементов, а потом ссылаетесь на них, чтобы генерировать случайный текст.

Редактор состоит из нескольких панелей:
- **Lists** (основная): Здесь пишем код списков.
- **Tester**: Тестируем выражения (например, вводим `[animal]` и видим результат).
- **HTML**: Для оформления вывода (стили, картинки).
- **Preview**: Живой предпросмотр генератора.

Чтобы начать: Зайди на perchance.org, нажми "Create" — откроется редактор. Сохраняй с Ctrl+S (нужен аккаунт или временная почта).

### 2. Как определять списки

Список — это имя, за которым следуют элементы с отступом (Tab или 2 пробела).

Пример простого списка:
```
animal
	свинья
	корова
	зебра
```

Чтобы вывести случайный элемент: `[animal]` (в панели Tester или в выводе).

**Иерархические списки** (списки внутри списков):
```
animal
	mammal  // подсписок млекопитающих
		кенгуру
		свинья
		человек
	reptile  // подсписок рептилий
		ящерица
		крокодил
```

- `[animal]` → выберет случайный **подсписок** (mammal или reptile), а потом элемент из него.
- `[animal.mammal]` → только из млекопитающих.

**Короткая запись для одного элемента** (удобно для шаблонов):
```
sentence = Это [animal] бегает по полю.
```
(Используй `=` вместо отступов, если список состоит из одного выражения.)

### 3. Вероятности (веса элементов)

По умолчанию все элементы равновероятны. Чтобы изменить:
- Добавь `^число` после элемента.
- `^2` — в 2 раза чаще.
- `^0.5` — в 2 раза реже.
- Дроби: `^1/10`.

Пример:
```
приправа
	перец ^3
	соль ^2
	чили ^0.1
	орегано
```

Перец будет выбираться чаще всего.

### 4. Короткие встроенные списки (curly braces {})

Для простых вариантов прямо в тексте:
```
предложение
	Это {очень|крайне|супер} {маленькое|крошечное} [animal]!
```

- `{a|b|c}` — случайный выбор из a, b или c.
- Можно с весами: `{большой|большой^3|огромный}` (большой в 4 раза чаще).
- Пробелы внутри {} важны: `{ hi | hello }` ≠ `{hi|hello}`.

Можно вкладывать: `{[animal]|[plant]}` — 50% животное, 50% растение.

### 5. Выбор нескольких элементов и уникальность

- `.selectOne` — выбрать один элемент (по умолчанию так работает `[list]`).
- `.selectMany(n)` — выбрать n элементов (с повторениями).
- `.selectUnique(n)` — выбрать n уникальных (без повторений).
- `.joinItems("разделитель")` — соединить в строку.

Пример:
```
fruit
	яблоко
	банан
	вишня
	груша
	апельсин
```

В выводе:
```
[fruit.selectUnique(3).joinItems(", ")]
```
→ "яблоко, банан, вишня" (все разные).

Или с кавычками:
```
[fruit.selectMany(2).joinItems("\", \"")]
```
→ "яблоко", "банан"

**Потребляемый список** (без повторений навсегда):
```
[fruits = fruit.consumableList]
[fruits]  // первый раз
[fruits]  // второй раз — уже без предыдущего
```

### 6. Переменные и логика (как JavaScript в [] )

Всё в квадратных скобках `[ ]` — это выражение, похожее на JS.

- Сохранить значение: `[var = выражение]`
Пример:
```
[pet = animal.selectOne]
Твой питомец — [pet] в прошлом: [pet.pastTense]
```

- Несколько действий: разделяй запятыми (выводит только последнее).
```
[a = animal.selectOne, "" ]  // выбрать, но ничего не выводить
```

- Условный выбор (динамические веса):
```
score = {1-10}
adjective
	плохой ^[score <= 3]
	средний ^[score > 3 && score <= 7]
	отличный ^[score > 7]
```

### 7. Полезные свойства (properties)

Цепочкой через точку:
- `.upperCase` — ВСЕ БОЛЬШИМИ
- `.lowerCase` — все маленькими
- `.titleCase` — Как Заголовок
- `.sentenceCase` — Первая большая
- `.pluralForm` — множественное число (cows от cow)
- `.singularForm` — единственное
- `.pastTense`, `.presentTense`, `.futureTense` — времена глаголов

Пример: `[animal.pluralForm.titleCase]` → "Зебры"

**Оператор ||** (или по умолчанию):
```
[pet.body || "шерсть"]  // если у pet нет body, то "шерсть"
```

### 8. Специальные символы

- `\s` — пробел (если нужно добавить вручную).
- `\t` — таб.
- `\\` — обратный слеш.
- `\[` — буквальная [.
- `\=` — буквальная =.

### 9. Импорт списков из других генераторов

```
{import:название-генератора}
```
Или конкретный:
```
animals = {import:animal-lists}
[animals.mammal]
```

Для экспорта: Определи `$output` с тем, что хочешь делить.

### 10. Оформление в HTML-панели

Вставляй теги:
- `<b>жирный</b>`
- `<i>курсив</i>`
- `<br>` — новая строка
- `<a href="ссылка">текст</a>`

Для сохранения пробелов: `<pre>[output]</pre>` или `white-space: pre-wrap;`
