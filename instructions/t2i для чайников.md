# Полный русскоязычный справочник  
Как создавать крутые генераторы изображений на Perchance.org  
с помощью text-to-image-plugin  
(Объясняю максимально просто, как для полного чайника)

### 1. Что это вообще такое и зачем нужно

Perchance.org — это сайт, где можно создавать генераторы случайного текста, персонажей, историй и т.д.  
А плагин **text-to-image-plugin** добавляет к этому суперспособность: по твоему текстовому описанию (промпту) он создаёт реальную картинку с помощью ИИ.

Примеры использования:
- Генератор фэнтези-персонажей с портретом
- Случайные пейзажи
- Обложки для историй
- Арты для настольных игр
- Мемы, аватарки, концепт-арты — всё, что захочешь

И самое классное — тебе почти не нужно уметь программировать. Всё делается простыми списками и парой строчек.

### 2. Как подключить плагин (обязательно первый шаг)

Зайди на perchance.org → Create (создать новый генератор).

В левом окне (Lists — редактор списков) напиши ровно эту строку:

```
image = {import:text-to-image-plugin}
```

Нажми Ctrl+S (сохранить). Всё! Плагин подключён и готов к работе.

### 3. Самый простой пример (чтобы сразу увидеть магию)

Скопируй вот этот код в Lists (замени всё, что там было):

```
character
	воин
	маг
	эльф-лучник
	орк
	дракон в человеческом облике
	пират
	киборг

place
	тёмный лес
	заснеженные горы
	пустыня под двумя лунами
	древний замок
	космическая станция

style
	в стиле фэнтези
	киберпанк
	студия Гибли
	масляная живопись
	цифровой арт

prompt
	[character] [place], [style], очень детализировано, шедевр

output
	[image(prompt)]
```

Теперь в правом нижнем окне (HTML) напиши просто:

```
[output]
```

Нажми Preview (или просто подожди) — через несколько секунд появится красивая картинка!

Нажми кнопку «randomize» (или обнови страницу) — получишь новую картинку по тому же описанию, но другую.

### 4. Как работает промпт (самое важное)

Промпт — это текстовое описание того, что ты хочешь увидеть. Чем лучше описание — тем круче картинка.

Хорошие советы для новичков:
- Пиши на английском — ИИ лучше понимает (но можно и на русском, просто результат чуть хуже).
- Добавляй слова: highly detailed, masterpiece, trending on artstation, 8k, sharp focus
- Указывай стиль: oil painting, digital art, studio ghibli, cyberpunk, realistic и т.д.

Пример крутого промпта:
```
beautiful elf princess in enchanted forest, sunset lighting, studio ghibli style, highly detailed, masterpiece
```

### 5. Основные настройки картинки (просто добавляй в список)

Создай список с настройками, например назови его `pic`:

```
pic
	prompt = beautiful cat in space, digital art, highly detailed
	resolution = 768x768    // варианты: 512x512, 768x768, 512x768, 768x512
	width = 500             // ширина в пикселях (высота подстроится автоматически)
	guidanceScale = 10      // от 1 до 30. Больше = точнее следует промпту, но может быть страннее. Обычно 7–12
	seed = 12345            // фиксированное число = всегда одна и та же картинка. -1 = случайная каждый раз
	negativePrompt = blurry, low quality, bad anatomy
	style = border:5px solid gold; border-radius:15px; box-shadow: 0 0 20px gold;
```

Потом в output пиши:

```
[image(pic)]
```

Можно делать сколько угодно разных списков настроек (pic1, pic2, hero, background и т.д.)

### 6. Как показать текст промпта под картинкой

Часто хочется, чтобы пользователь видел, какое описание использовалось.

Самый простой способ:

```
output
	[image(prompt)] <br><br>
	<small>Промпт: [lastTextToImagePrompt]</small>
```

`lastTextToImagePrompt` — волшебная переменная, которая всегда содержит последний использованный промпт.

Если хочешь зафиксировать промпт (чтобы он не менялся при randomize):

```
output
	[p = prompt.evaluateItem]
	[image(p)] <br><br>
	<small>Промпт: [p]</small>
```

### 7. Несколько картинок на странице

Просто пиши несколько раз:

```
output
	[image(pic1)] <br><br>
	[image(pic2)] <br><br>
	[image(pic3)]
```

Или в таблице, в ряд, как захочешь — всё через HTML.

### 8. Удаление фона (прозрачный фон)

Добавь в настройки:

```
removeBackground = true
```

Получишь картинку на прозрачном фоне (PNG). Идеально для персонажей, предметов и т.д.

### 9. Галерея сохранённых картинок

Пользователи могут сохранять понравившиеся картинки в общую галерею твоего генератора.

Чтобы показать галерею прямо на странице:

```
gallerySettings
	gallery = true
	sort = recent          // или top, trending
	timeRange = all-time   // или 1-day, 1-week, 1-month и т.д.
	adaptiveHeight = true  // галерея растянется по высоте без скролла внутри
	style = height:80vh;   // высота галереи

output
	<h2>Галерея лучших работ</h2>
	[image(gallerySettings)]
```

### 10. Кнопка "Попробовать ещё раз" для одной картинки

Если хочешь отдельную кнопку только для перегенерации одной картинки:

```
pic
	prompt = ...
	id = myUniqueImage     // любое уникальное имя

output
	[image(pic)]
	<button onclick="myUniqueImage.reload()">Попробовать ещё раз</button>
```

### 11. Полезные готовые трюки

- Квадратные картинки: resolution = 512x512 или 768x768
- Портрет (вертикальные): resolution = 512x768
- Пейзаж (горизонтальные): resolution = 768x512
- Большая детализация: добавь в промпт "8k, ultra detailed, sharp focus"
- Меньше странностей: negativePrompt = deformed, ugly, bad anatomy, extra limbs
