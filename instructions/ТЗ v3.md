# ТЗ V3.1: VELORIA (краткая версия)

## 1. Цель
	Создать на Perchance генератор изображений для взрослых с контролем через промт для модели Flux/Chroma,используя text-to-image-plugin и ai-text-plugin.

## 2. Архитектура

	· Lists-редактор: Только импорт плагинов и данные (generatorData).
     	· HTML-редактор: Весь интерфейс, логика, стили (CSS), генерация.
     	· Плагины:
     		· T2i = {import:text-to-image-plugin} (генерация)
     		· Ai = {import:ai-text-plugin} (улучшение промта)
     		· Upload = {import:upload-plugin} (сохранение)

## 3. Модель данных (generatorData)

	Объект в Lists-редакторе со всеми опциями из Приложения.Структура: вложенные списки объектов с id, name (для UI) и prompt (фрагмент на англ.).
	Ключевое дополнение: Для сцен с несколькими персонажами в UI добавляется выбор "Активный субъект" и "Пассивный объект" для определения, кто совершает действие над кем.
	Пример элемента: { id: 'oral_male', name: 'Минет', prompt: 'sucking {target}\'s penis' }


## 4. Логика сборки промта (Prompt Assembly Logic)
	
	Основной принцип: Описание от общего к частному для лучшего восприятия моделью.

### 4.1. Алгоритм функции buildPrompt(userSelections)
1. Сцена и контекст (Context)
       [environment.prompt] with [lighting.prompt], creating a [atmosphere.prompt] atmosphere.
2. Персонажи (общее описание)
       [count.prompt] [gender.prompt] [age.prompt] with [bodyExpression.prompt].
3. Ядро действия (Core Action)
       [activeSubject] is [primaryAction.prompt] [passiveTarget].
   · Токен {target} в действии заменяется на the viewer (режим FPV) или a second [gender.prompt].
4. Детализация (Details)
       [pose.prompt], with [bodyType.prompt], [breastSize.prompt], [penisSize.prompt], [skinDetails.prompt].
			· Добавляются модификаторы действий (actionModifiers), выражения лица (facialExpressions), жидкости (fluids), элементы фетишей.
5. Стиль и ракурс (Style & Composition)
       The scene is rendered in [style.prompt] style, with [cameraEffects.prompt], [cameraAngles.prompt].
6. Гарантии качества (Quality Boilerplate)
       Автоматически добавляется фиксированный суффикс:
       aesthetic, masterpiece, highly detailed, photorealistic, 8k resolution, realistic anatomy, accurate human proportions, standard number of fingers and toes, five fingers on each hand, five toes on each foot, two arms, two legs.

### 4.2. Грамматическая обработка
	· Автоматическое согласование единственного/множественного числа.
	· Динамические связки (, with, and, , while) и усилители (beautiful, stunning), выбираемые случайно для естественности.
	· Замена {target} выполняется на этапе сборки.

### 4.3. Advanced Mode
	· В интерфейсе доступно текстовое поле (textarea) с готовым промтом.
	· Пользователь может его редактировать вручную.
	· Кнопки:
	· "Улучшить через AI" → отправляет текущий текст в ai-text-plugin.
	· "Сбросить к настройкам UI" → восстанавливает промт из текущих настроек.

	Вся логика выполняется в HTML/JS, результат присваивается переменной finalPrompt для передачи в image().

## 5. Пользовательский интерфейс (UI/UX)

### 5.1. Общая структура

· Экран делится по вертикали в пропорции 55% / 45%.
· Левая панель (55%): Вертикальный скролл с аккордеонами всех настроек.
· Правая панель (45%): Фиксированная (sticky) зона просмотра. Всегда видна на экране и содержит:
  1. Верхняя часть: Краткий тезис генератора (напр., "Veloria — где желание становится искусством").
  2. Основная часть: Вертикальный скролл-область (viewport) для отображения сгенерированных изображений в виде карточек.
  3. Нижняя часть: Кнопка запуска генерации "ECSTASY".

### 5.2. Управление изображениями (Галерея)

· Базовая карточка: Превью изображения, при клике открывается попап.
· Полноэкранный попап:
  · Изображение на весь экран.
  · Навигация "влево-вправо" для листания по массиву сгенерированных картинок.
  · Кнопки управления: "Скачать" (загрузка файла), "В галерею" (сохранение через плагин), "Копировать промт/seed" (для повторения).
  · Отображение метаданных (использованный промт, seed).

### 5.3. Адаптация

· На экранах с шириной менее 768px макет переключается на вертикальный стек (100% ширины).

## 6. Работа с плагинами (исправленная и конкретная)

### 6.1. Импорт и инициализация (Lists Editor)

```
T2i = {import:text-to-image-plugin}
Ai = {import:ai-text-plugin}
Upload = {import:upload-plugin}
```

### 6.2. Генерация изображения (в HTML/JS)

```javascript
async function generateImage() {
    // 1. Сбор промта из UI
    const finalPrompt = buildPrompt(userSelections);

    // 2. Вызов text-to-image-plugin
    const result = await T2i({
        prompt: finalPrompt,
        negativePrompt: "Extra fingers, mutated hands...", // фикс. из ТЗ
        resolution: "512x512",
        guidanceScale: 7,
        seed: userSelections.seed || -1,
        // Важно для галереи:
        saveTitle: `Veloria: ${userSelections.primaryAction?.name || 'Generation'}`,
        saveDescription: finalPrompt
    });

    // 3. Сохранение результата в массив и отрисовка карточки
    generatedImages.push(result);
    renderImageCard(result);
}
```

### 6.3. Улучшение промта через AI (Advanced Mode)

```javascript
async function improvePrompt() {
    const improved = await Ai({
        instruction: "Improve, enrich, and beautify this image description. Keep the core meaning and key terms. Respond only with the improved prompt.",
        startWith: document.getElementById('advancedPromptTextarea').value
    });
    // Подставляем улучшенный текст обратно в поле
    document.getElementById('advancedPromptTextarea').value = improved.generatedText;
}
```

### 6.4. Сохранение картинки через Upload-plugin (кнопка "В галерею")

```javascript
async function saveToUploadService(imageDataUrl) {
    // 1. Конвертируем DataURL в Blob
    const blob = await (await fetch(imageDataUrl)).blob();

    // 2. Загружаем через плагин, получаем прямую ссылку
    const uploadResult = await Upload(blob, {
        expires: Date.now() + (1000 * 60 * 60 * 24 * 7) // Файл хранится 7 дней
    });

    // 3. Ссылку можно показать пользователю или автоматически сохранить
    alert(`Изображение сохранено! Ссылка: ${uploadResult.url}`);
}
```
