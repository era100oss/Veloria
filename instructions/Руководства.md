
📘 Полное руководство по плагину ai-text-plugin

Плагин ai-text-plugin позволяет генерировать и дорабатывать тексты с помощью искусственного интеллекта прямо внутри генераторов Perchance. Он работает через внешний сервис.

🚨 Важные предупреждения

· Реклама: Как и text-to-image-plugin, этот плагин финансируется за счет рекламы, которая будет показываться неавторизованным пользователям.
· Скорость и доступность: Генерация текста происходит на внешнем сервере. Скорость и доступность зависят от нагрузки на сервер и качества вашего интернет-соединения.
· Контент: Вы отвечаете за контент, генерируемый с помощью этого плагина.


📥 Импорт плагина

Добавьте эту строку в верхней части панели Lists вашего генератора:

```perchance
Ai = {import:ai-text-plugin}
```

✨ Базовый синтаксис и метод .generate()

Основной метод для генерации текста — .generate(). Он принимает объект с настройками, где ключ prompt (или input) является обязательным.

Самый простой пример:

```perchance
Output = [ai.generate(prompt = “Напиши короткую сказку о драконе”)]
```

Основные параметры метода .generate():

· prompt (или input): Обязательный. Текстовый запрос для ИИ. Можно передавать переменные из других списков.
· model: Модель ИИ для использования. Например, claude-3-haiku, gpt-4o-mini. Доступные модели могут меняться.
· temperature: “Творчество” ответа (от 0.0 до 2.0). Низкие значения (0.1-0.7) дают более предсказуемые результаты, высокие (0.8-1.3) — более креативные и случайные.
· maxTokens: Максимальная длина ответа в токенах (примерно 0.75 токена на 1 слово). Для длинных текстов указывайте 500-1000.
· system: Системный промпт, который задает роль или контекст для ИИ (например, “Ты — помощник, который пишет в деловом стиле”).
· seed: Числовое значение для воспроизводимости результата.

Пример 1: Генератор идей для историй

```html
  // Вызываем функцию из панели Lists и вставляем результат
  Document.getElementById(‘result’).innerHTML = getAItext();

```


💡 Советы по использованию

1. Четкие инструкции: Чем конкретнее и яснее prompt, тем лучше результат. Вместо «Напиши что-нибудь» используйте «Напиши краткое описание персонажа-эльфа-разведчика, его внешность и характер».
2. Экспериментируйте с temperature: Для задач, требующих точности (факты, инструкции), используйте низкое значение (0.1-0.3). Для творческих задач (стихи, истории, идеи) — более высокое (0.7-1.0).
3. Контролируйте длину: Используйте maxTokens, чтобы не получать слишком длинные или обрезанные ответы. Для абзаца текста достаточно 150-300 токенов.
4. Используйте system для контекста: Этот параметр помогает задать тон, стиль или роль для ИИ на протяжении всего диалога (если вы строите его).

📘 Полное руководство по плагину upload-plugin

Плагин upload-plugin позволяет программно загружать данные (текст, файлы) на сервер хранения Perchance и получать на них прямую ссылку. Это аналог ручной загрузки на perchance.org/upload, но управляемый кодом внутри вашего генератора.

⚠️ Критически важное предупреждение

· Не форкайте этот плагин! Предоставленная документация — это форк/ремикс. Код плагина тесно связан с серверным кодом Perchance. Если серверный код будет обновлён, ваша версия плагина, скорее всего, сломается.
· Что делать вместо форка: 1) Просите новые функции на официальном форуме сообщества. 2) Создайте новый плагин-обёртку, который импортирует оригинальный {import:upload-plugin} и расширяет его функциональность.


📥 Импорт плагина

Добавьте эту строку в верхней части панели Lists вашего генератора:

```perchance
Upload = {import:upload-plugin}
```


⚙️ Базовый синтаксис и использование

Основная функция — upload(). Она является асинхронной (async), поэтому должна вызываться внутри асинхронных функций с использованием await.

Простой пример загрузки текста:

```perchance
// Функция должна быть async
Async saveMyText() =>
  // Вызов upload() с await
  Let result = await upload(“Этот текст будет загружен как .txt файл”);
  // result.url — прямая ссылка на файл
  Output = result.url;
```

Что можно загружать:

· Строка (String): Будет загружена как текстовый файл (.txt).
· Blob-объект: Позволяет загружать бинарные данные (например, изображения).


📤 Возвращаемые данные и обработка ошибок

Функция upload() возвращает объект со следующими свойствами:

· url (строка): Прямая ссылка на загруженный файл. Основная цель плагина.
· size (число): Размер загруженного файла в байтах.
· error (null или строка): null, если ошибки не было. В случае ошибки содержит её код, например:
  · “over_daily_allowance”: Превышена дневная квота на загрузки.
  · “file_too_big”: Файл превышает максимальный размер.
  · “invalid_filetype”: Неподдерживаемый тип файла.
· deletionUrl (строка): Специальный URL для удаления этого файла (доступно в течение 3 дней).

Пример обработки:

```perchance
Async processUpload() =>
  Let { url, size, error, deletionUrl } = await upload(myData);
  If (error) {
    Output = `Ошибка загрузки: ${error}`;
  } else {
    Output = `Файл загружен! Ссылка: ${url}, Размер: ${size} байт.`;
    // deletionUrl можно сохранить для будущего удаления
  }
```


🕒 Временные файлы (Ключевая возможность)

Если файл нужен временно, используйте параметр expires. Это даёт огромное увеличение лимитов на размер файла и дневную квоту.

· Срок истечения указывается в миллисекундах с 1 января 1970 года (Unix-время).
· Чем короче срок — тем выше лимиты:
  · expires <= 24 часа: увеличение лимитов в 400 раз.
  · expires = 1 год: увеличение лимитов в 20 раз.

Пример загрузки файла, который удалится через 24 часа:

```perchance
Async saveTemporary() =>
  // Date.now() — текущее время в мс. Прибавляем 24 часа (1000мс * 60сек * 60мин * 24ч)
  Let expiryTime = Date.now() + (1000 * 60 * 60 * 24);
  Let { url } = await upload(“Временные данные”, {expires: expiryTime});
  Output = `Временная ссылка (живёт 24ч): ${url}`;
```

Важно: Файл гарантированно проживёт не меньше указанного срока, но может быть удалён и позже.


🗑️ Ручное удаление файлов

Загруженные файлы можно удалить вручную в течение 3 дней после загрузки, отправив GET-запрос на полученный deletionUrl.

Пример функции удаления:

```perchance
Async deleteUploadedFile(deletionUrl) =>
  Let response = await fetch(deletionUrl);
  Let { success } = await response.json();
  If (success) {
    Output = “Файл успешно удалён.”;
  } else {
    Output = “Не удалось удалить файл (возможно, истёк 3-дневный лимит).”;
  }
```


💡 Практические примеры и советы

Пример 1: Сохранение результата работы генератора


Совет по экономии лимитов (из документации): Для текстовых данных вы можете использовать сжатие перед загрузкой и распаковку при скачивании. Это позволяет уместить в ~10 раз больше данных в рамках лимита на размер файла. Конкретные методы сжатия нужно искать в примерах на сайте Perchance.

Области применения (как в документации):

· Кнопка “Сохранить результат” в генераторе.
· Создание персонажа для чата ИИ и генерация ссылки для его шаринга (как в perchance.org/ai-chat).
· Любые сценарии, где нужно получить публичную ссылку на сгенерированные данные.

📘 Полное руководство по плагину kv-plugin

Плагин kv-plugin предоставляет простое хранилище типа «ключ-значение» (key-value store) прямо в браузере пользователя, используя IndexedDB. Это позволяет вашим генераторам Perchance сохранять данные локально на устройстве пользователя между сессиями.

⚠️ Важные особенности и ограничения

· Локальное хранилище: Данные сохраняются в браузере конкретного пользователя и на конкретном устройстве. Они не синхронизируются между устройствами и не доступны вам как создателю.
· Не является облачным: Это не серверная база данных. Если пользователь очистит историю браузера или кэш, данные могут быть удалены.
· Идеальное применение: Сохранение пользовательских настроек, прогресса в игре, черновиков, последних введённых данных и т.д. в рамках одного генератора.


📥 Импорт плагина

Добавьте эту строку в верхней части панели Lists вашего генератора:

```perchance
Kv = {import:kv-plugin}
```

После импорта объект kv будет доступен с основными асинхронными методами для работы с данными.


⚙️ Основные методы (API)

Все методы плагина являются асинхронными (async). Для их вызова внутри функций Perchance вам нужно использовать ключевое слово await.

1.	Kv.set(key, value) → Сохранить или обновить данные

Сохраняет значение по указанному ключу. Ключом должна быть строка. Значением может быть любой тип данных, поддерживаемый JSON (строка, число, массив, объект и т.д.).

Пример:

```perchance
Async saveUserData() =>
  // Сохраняем объект с данными по ключу “userProfile”
  Await kv.set(“userProfile”, { name: “Алексей”, level: 5, theme: “dark” });
  Output = “Данные успешно сохранены!”;
```

2.	Kv.get(key) → Получить данные

Извлекает значение, сохранённое по указанному ключу. Если ключ не найден, вернёт undefined.

Пример:

```perchance
Async loadUserData() =>
  // Пытаемся загрузить данные
  Let userData = await kv.get(“userProfile”);
  If (userData) {
    Output = `Добро пожаловать назад, ${userData.name}! Ваш уровень: ${userData.level}.`;
  } else {
    Output = “Сохранённых данных не найдено.”;
  }
```

3.	Kv.update(key, updateFunction) → Обновить данные (умный метод)

Позволяет обновить значение на основе его предыдущего состояния. Метод передаёт текущее значение (или undefined) в вашу функцию, а её результат сохраняется как новое значение.

Пример (увеличение счётчика):

```perchance
Async incrementCounter() =>
  Await kv.update(“clickCount”, (currentValue = 0) => currentValue + 1);
  Let newCount = await kv.get(“clickCount”);
  Output = `Счётчик кликов: ${newCount}`;
```

4.	Kv.delete(key) → Удалить данные

Удаляет пару ключ-значение из хранилища.

Пример:

```perchance
Async clearProfile() =>
  Await kv.delete(“userProfile”);
  Output = “Профиль очищен.”;
```

5.	Kv.clear() → Очистить всё хранилище

Удаляет все данные, сохранённые этим плагином для вашего генератора.

Пример:

```perchance
Async factoryReset() =>
  Await kv.clear();
  Output = “Все локальные данные сброшены.”;
```

6.	Kv.keys() → Получить список всех ключей

Возвращает массив строк — все ключи, которые сейчас есть в хранилище для этого генератора.

Пример:

```perchance
Async listAllData() =>
  Let allKeys = await kv.keys();
  Output = `В хранилище найдены ключи: ${allKeys.join(“, “)}`;
```

Пример 1: Сохранение темы оформления (тёмная/светлая)

```perchance
    // … применяем тему …

```

Пример 2: Простая игра с сохранением прогресса

```perchance
Kv = {import:kv-plugin}
// Функция сохранения прогресса
Async saveGame(level, score) =>
  Await kv.set(“gameProgress”, { currentLevel: level, bestScore: score });
// Функция загрузки игры
Async loadGame() =>
  Let progress = await kv.get(“gameProgress”);
  If (progress) {

    Output = “Новая игра!”;
  }
```

Пример 3: Сохранение черновика текста (с использованием update)

```perchance
Kv = {import:kv-plugin}
// Пользователь набирает текст в textarea с id=”draftInput”
Async autoSaveDraft() =>
  Let draftText = document.getElementById(“draftInput”).value;
  // Сохраняем с меткой времени
  Await kv.update(“textDraft”, (oldDraft = {}) => ({
    …oldDraft,
    Text: draftText,
    lastSaved: new Date().toLocaleTimeString()
  }));

```


🔧 Технические детали и советы

· Асинхронность: Всегда используйте async/await. Не используйте .then() внутри списков Perchance.
· Объём данных: Лимиты IndexedDB очень велики (обычно более 50 МБ на домен), вы вряд ли упрётесь в них.
· Изоляция: Данные изолированы не только по домену (perchance.org), но и по имени конкретного генератора. Два разных генератора не увидят данные друг друга.
· Безопасность: Не храните в kv пароли, токены или другую действительно конфиденциальную информацию.
· Совместимость: Для более сложных сценариев хранения состояний рассмотрите связку kv-plugin + remember-plugin.
