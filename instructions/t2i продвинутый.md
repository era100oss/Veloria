# Продвинутый справочник по text-to-image-plugin  
Как использовать плагин по-настоящему мощно с помощью JavaScript в Perchance  
(Объясняю просто, но с полным раскрытием механизма — для тех, кто хочет делать крутые генераторы)

### 1. Как плагин работает под капотом (просто и понятно)

Когда ты пишешь `{import:text-to-image-plugin}`, Perchance подгружает готовую JavaScript-функцию с именем **image**.

Эта функция **image()** — главная звезда плагина.  
Она может:
- Принимать текст или объект с настройками
- Генерировать картинку на сервере
- Возвращать специальный объект, который автоматически превращается в картинку на странице

Важно: всё происходит асинхронно (картинка генерируется не мгновенно, а через 5–20 секунд).

### 2. Простой способ (без JS) — для понимания основы

Ты уже знаешь:
```
pic
	prompt = кот в космосе
	resolution = 512x768

output
	[image(pic)]
```

Здесь Perchance автоматически вызывает функцию image(pic) и вставляет результат (iframe с картинкой).

### 3. Продвинутый способ — прямой вызов image() в JavaScript

Чтобы делать сложные вещи (динамические промпты, обработка после генерации, несколько попыток, коллажи и т.д.), нужно использовать JavaScript.

Где писать JS в Perchance?
- В Lists: в выражениях внутри `[ ]`
- В HTML: в теге `<script>` или в onclick=""
- Лучше всего — создать функцию start() или init()

### 4. Что принимает функция image()

Два варианта вызова:

**Вариант A: простая строка (только промпт)**
```js
image("милый котёнок в стиле студии Гибли")
```

**Вариант B: объект с настройками (рекомендуется для продвинутых)**
```js
image({
  prompt: "милый котёнок в стиле студии Гибли",
  resolution: "512x768",
  guidanceScale: 12,
  negativePrompt: "уродливый, размытый",
  removeBackground: true,
  seed: 12345
})
```

**Вариант C: строка + объект (удобно для быстрого задания опций)**
```js
image("милый котёнок", {resolution: "768x512", removeBackground: true})
```

### 5. Что возвращает image() — самое важное!

Функция image() возвращает **Promise** (обещание), который:
- При использовании в [ ] автоматически превращается в HTML-код картинки (iframe)
- При использовании с `await` даёт полный доступ к результату

После завершения генерации ты получаешь объект со свойствами:
<pre>
| Свойство              | Что это                                                                 |
|-----------------------|-------------------------------------------------------------------------|
| `dataUrl`             | Готовая картинка в формате data:url (строка) — можно вставить в `<img src="">` |
| `canvas`              | HTML5 Canvas-элемент с картинкой — можно рисовать поверх, менять фильтры |
| `inputs`              | Все настройки, которые реально использовались (включая seed)           |
| `iframe`              | Сам iframe-элемент (если он есть на странице)                           |
| `toString()` или просто объект | Автоматически возвращает HTML-код iframe для вставки в Perchance       |
</pre>
### 6. Примеры использования с await (самое мощное)

Создай в Lists функцию:

```
start() =>
	// Пример 1: простая генерация и вставка в img
	let img = document.createElement("img")
	img.style.maxWidth = "600px"
	img.style.border = "5px solid gold"
	let result = await image("фэнтези замок на горе, закат, детализировано")
	img.src = result.dataUrl
	document.body.appendChild(img)

	// Пример 2: с объектом настроек
	let cat = await image({
		prompt: "рыжий кот в коробке, милый, студия Гибли стиль",
		resolution: "512x512",
		removeBackground: true,
		guidanceScale: 10
	})
	let catImg = document.createElement("img")
	catImg.src = cat   // можно просто cat, потому что toString() возвращает dataUrl
	document.body.appendChild(catImg)

	// Пример 3: используем реальный seed из результата
	console.log("Использованный seed:", cat.inputs.seed)
```

Чтобы запустить — добавь в HTML:
```
<script>[start()]</script>
```

### 7. Как перегенерировать картинку (кнопка "ещё раз")

```js
// В Lists
pic
	prompt = дракон в пещере
	id = dragonImage

// В HTML
<div id="container"></div>
<button onclick="regenerate()">Ещё один дракон!</button>

<script>
async regenerate() =>
	container.innerHTML = ""  // очищаем старое
	let result = await image({
		prompt: pic.prompt.evaluateItem,
		id: "dragonImage"  // важно то же id!
	})
	container.appendChild(result.canvas)  // или result.iframe
</script>
```

Или проще — используй встроенный reload():
```
[image(pic.with({id:"myPic"}))]
<button onclick="myPic.reload()">Перегенерировать</button>
```

### 8. Продвинутые фичи через onFinish

Можно задать функцию, которая выполнится после генерации:

```js
async start() =>
	let result = await image({
		prompt: "волк в лесу ночью",
		onFinish(output) =>
			// Эта функция вызовется, когда картинка готова
			console.log("Готово! Seed:", output.inputs.seed)
			// Можно изменить картинку
			output.canvas.getContext("2d").filter = "contrast(1.5)"
			let newDataUrl = output.canvas.toDataURL()
			someImg.src = newDataUrl
	})
	// result здесь ещё не готов — ждём внутри onFinish
```

### 9. Полный список всех параметров (объекта настроек)
``` html
<pre>
| Параметр                | Тип          | Описание                                                                 | Пример |
|-------------------------|--------------|--------------------------------------------------------------------------|--------|
| `prompt`                | строка       | Основное описание                                                        | "кот на луне" |
| `negativePrompt`        | строка       | Что НЕ должно быть в картинке                                            | "размыто, уродливо" |

| `width` / `height`      | число        | Размер в пикселях (один можно опустить — подстроится)                    | 600 |

</pre>
```
### 10. Заключение: когда использовать JS, а когда простой способ

- **Простой способ** (`[image(pic)]`) — для 90% генераторов: быстро, красиво, надёжно.
- **JavaScript + await** — когда нужно:
  - Динамически менять промпт
  - Обрабатывать картинку после генерации (фильтры, текст поверх, коллажи)
  - Делать "генерировать ещё" с логикой
  - Создавать интерактивные чаты с ИИ-картинками
  - Делать сложные галереи или эффекты
