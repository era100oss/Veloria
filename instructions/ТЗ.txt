1.	Введение и цели

Создать на платформе Perchance генератор изображений для взрослых с детальным контролем через текстовый промт, используя плагин text-to-image-plugin (Chroma/Flux-based). Генератор предназначен для пользователей, подтвердивших возраст. 
Предоставить пользователю интуитивный интерфейс для создания сложных, детализированных промтов без необходимости ручного написания.
2.	Архитектура и технические основы

2.1.	Гибридная архитектура (Принятое решение)

· Lists Editor Perchance используется исключительно для импорта необходимых плагинов.
· HTML Editor Perchance содержит всю бизнес-логику, модель данных, интерфейс (HTML/CSS/JavaScript) и функции работы с плагинами.

2.2.	Используемые плагины Perchance

Импорт в Lists Editor:

```perchance
T2i = {import:text-to-image-plugin}
Ai = {import:ai-text-plugin}
Upload = {import:upload-plugin}
Kv = {import:kv-plugin}
```

Примечание: kv-plugin и upload-plugin — опциональны, их использование зависит от реализации дополнительных функций (сохранение настроек, черновиков).

2.2.1.	Text-to-image-plugin (Основной движок)

· Глобальный объект: window.image
· Вызов: await image({prompt, negativePrompt, resolution, guidanceScale, seed, …})
· Поддерживаемые разрешения: 512x512, 512x768, 768x512, 768x768.
· Галерея: Использование встроенной функции сохранения изображений на сервер Perchance с параметрами saveTitle и saveDescription.

2.2.2.	Ai-text-plugin (Улучшение промтов)

· Глобальный объект: window.ai
· Вызов: await ai({instruction, startWith, …}) для переформулирования и расширения пользовательских промтов.

2.2.3.	Upload-plugin (Опционально)

· Для программной загрузки данных (например, экспорта настроек в JSON).

2.2.4.	Kv-plugin (Опционально)

· Для локального сохранения в браузере пользователя предустановок, истории или избранных комбинаций настроек.

5.5.	Логика сборки промта (Prompt Assembly Logic)



5.1.	Алгоритм функции buildPrompt(userSelections)



1.	Инициализация: На основе userSelections.sceneMode определить активные блоки.

2.	Уровень 1. Ядро сцены:
Если включен FPV:
  · "From the viewer's perspective, "
· Это явно задает контекст от первого лица для всей последующей сцены.
   · Сборка описания персонажа: Для каждого персонажа.
     · Возраст: Если выбран тип range, сгенерировать случайное число: Math.floor(Math.random() * (max – min + 1)) + min и создать строку {число} year old. Если тип category, использовать prompt.
     · Собрать строку: [count] [ageString] [gender] [bodyType] [breastSize] [penisSize] [skinDetails].
   · Основное действие: [character1] is [action.prompt] [character2/viewer]. Заменить {target} на the viewer если включен FPV, или на описание второго персонажа.
   · Окружение: [environment.prompt].
3.	Уровень 2. Детализация: (добавляются через запятые и союзы)
   · Поза, модификаторы действий, фетиш-компоненты, выражения лица, жидкости, одежда/роли, детали тела, освещение, эффекты камеры.
  · Ракурс камеры: Добавить выбранные пользователем фрагменты из cameraAngles. Они должны вписываться в описание естественно, часто в начале предложения или через запятую.
  · Пример сборки: "[angle.prompt], [distance.prompt], [focus.prompt], [fov.prompt]"

Пример итогового промта с учетом FPV и ракурсов:

"From the viewer's perspective, a 24 year old woman with a slim body is performing oral sex, kneeling on the floor of a modern office. Shot from a low angle, looking up, close-up focus on the mouth and lips, with a narrow field of view. Her face shows a look of pleasure, and soft side lighting highlights the curves of her body. The scene has a sensual atmosphere, rendered in a photorealistic style with sharp details. ... [финальный суффикс]"
4.	Уровень 3. Стиль и гарантии:
   · The scene has a [atmosphere] atmosphere.
   · Rendered in a [style] style.
   · Автоматически добавить обязательный финальный суффикс, в соответствии со стилем.
5.	Грамматическая обработка: Обеспечить связность, использовать причастия (-ing), союзы.
6.	Контроль длины: Автоматическое обогащение.

6. Пользовательский интерфейс (UI/UX)

6.1. Общий принцип

· Мобильный-first дизайн. Вертикальная прокрутка. Основной упор на удобство использования на смартфоне.
· Группировка в аккордеоны/вкладки. Для управления многочисленными опциями.
· Визуальная индикация совместимости. Вместо динамического скрытия несовместимые опции становятся полупрозрачными или помечаются иконкой ⚠️. При наведении/тапе показывается подсказка: “Несовместимо с выбранным действием ‘X’”.
· Режим сцены (Scene Mode) — главный переключатель вверху интерфейса, определяющий доступные секции.

6.2. Структура интерфейса (вертикальный поток)

1. Шапка: Выбор Scene Mode (Primary/Fetish/Composite). Кнопка Randomize All.
2. Секция “Персонажи”: Аккордеон с настройками количества, пола, возраста, телосложения, груди, пениса, кожи. Для пары — настройки для второго персонажа.
3. Секция “Действие и Поза”:
   · Выпадающий список “Основное действие” (заполняется в зависимости от Scene Mode).
   · Выпадающий список “Поза” (динамически фильтруется согласно compatibilityMatrix).
   · Чекбокс FPV (First Person View).
4. Секция “Фетиши и Детали”: Несколько аккордеонов (Feet Fetish, BDSM, Ролевые игры и т.д.). Внутри — выбор действий, поз, атрибутов. Активно в режимах fetish и composite.
5. Секция “Модификаторы”: Аккордеоны для Выражения лица, Жидкости, Одежда и роли, Детали тела.
6. Секция “Сцена и Стиль”: Выпадающие списки для Окружения, Освещения, Атмосферы, Стиля изображения, Эффектов камеры, Камера и ракурс.
Элементы управления Камера и ракурс;
1. Чекбокс: "Перспектива от первого лица (FPV)".
2. Выпадающий список: "Угол съемки" (с вариантами из cameraAngles.angle).
3. Выпадающий список: "План / Дистанция" (с вариантами из cameraAngles.distance).

· Раскрывающийся textarea под кнопкой генерации, отображающий итоговый промт.

7. Работа с плагинами: ключевые функции

7.1. Генерация изображения async function generateImage()

```javascript
Async function generateImage(userSelections, isAdvancedMode, advancedPrompt) {
    Const finalPrompt = isAdvancedMode ? advancedPrompt : buildPrompt(userSelections);
    Const negativePrompt = “Extra fingers, mutated hands, fused bodies, cloned faces, missing limbs, malformed anatomy, extra legs, extra arms, double heads, disfigured, blurry, low quality, cartoon, illustration, distorted fingers, merged limbs”;
    
    Const settings = {
        Prompt: finalPrompt,
        negativePrompt: negativePrompt,
        resolution: userSelections.resolution,
        guidanceScale: 7,
        seed: userSelections.seed || undefined,
        model: “flux”
    };

    Try {
        Const result = await window.image(settings);
        // result содержит URL изображения, данные для галереи и т.д.
        Return result;
    } catch (error) {
        Console.error(“Generation failed:”, error);
        // Обработка ошибки для пользователя
    }
}
```

7.2. Работа с галереей

Использовать встроенную функцию сохранения плагина text-to-image-plugin:

```javascript
// При генерации с опцией “Автосохранение в галерею”
Const saveResult = await window.image({
    …settings,
    saveTitle: “My Generation”, // Можно сгенерировать из настроек
    saveDescription: finalPrompt // Сохранять промт в описании
});
```

7.3. Локальное сохранение (Kv-plugin)

```javascript
// Сохранение избранной комбинации настроек
Async function savePreset(presetName, userSelections) {
    Await window.kv.set(`preset_${presetName}`, userSelections);
}
```
