Подробная информация о плагине t2i (text-to-image) и продвинутые методы использования:

1. ОСНОВНЫЕ ВОЗМОЖНОСТИ:
   - Генерация изображений по текстовому описанию (промпту)
   - Поддержка различных разрешений (512x512, 512x768, 768x512, 768x768)
   - Управление параметрами генерации через опции
   - Возврат результата в виде data URL или структурированного объекта

2. БАЗОВЫЙ СИНТАКСИС:
   ```javascript
   let imageData = await generateImage(prompt, options);
   ```
   - prompt: текстовое описание изображения (обязательно)
   - options: объект с дополнительными параметрами (необязательно)

3. ДОСТУПНЫЕ ОПЦИИ:
   ```javascript
   {
     resolution: "768x768",  // Разрешение: "512x512", "512x768", "768x512", "768x768"
     seed: 12345,           // Число для воспроизводимости результата
     model: "sdxl"          // Модель генерации (если доступны варианты)
   }
   ```

4. ПРОДВИНУТЫЕ МЕТОДЫ ИСПОЛЬЗОВАНИЯ:

   А. Управление разрешением:
   ```javascript
   // Вертикальное изображение (например для портрета)
   let verticalImage = await generateImage("портрет девушки", {resolution: "512x768"});
   
   // Горизонтальное изображение (например для пейзажа)
   let landscapeImage = await generateImage("горы на закате", {resolution: "768x512"});
   
   // Высокое разрешение
   let highResImage = await generateImage("детализированный космос", {resolution: "768x768"});
   ```

   Б. Воспроизводимость результатов:
   ```javascript
   // Генерация с одинаковым seed даст одинаковый результат
   let image1 = await generateImage("красный дракон", {seed: 12345});
   let image2 = await generateImage("красный дракон", {seed: 12345}); // Идентично image1
   ```

   В. Работа с результатами:
   ```javascript
   // Получение данных как data URL
   let dataUrl = await generateImage("абстрактное искусство");
   
   // Получение структурированных данных
   let imageData = await generateImage("город будущего", {resolution: "768x768"});
   console.log(imageData.prompt); // Оригинальный промпт
   console.log(imageData.imageUrl); // Data URL изображения
   console.log(imageData.base64); // Base64 без префикса
   console.log(imageData.timestamp); // Время генерации
   ```

   Г. Оптимизация промптов:
   - Добавление стилей: "в стиле Ван Гога", "фотореализм", "аниме"
   - Уточнение деталей: "высокая детализация", "4K", "кинематографическое освещение"
   - Управление композицией: "крупный план", "с высоты птичьего полета"
   - Указание настроения: "мрачная атмосфера", "веселый и яркий"
   
   Пример продвинутого промпта:
   ```javascript
   let complexPrompt = "Футуристический мегаполис в стиле киберпанк, 
                        неоновые вывески, дождь на улицах, 
                        кинематографическое освещение, 
                        высокая детализация, 4K, фотореализм";
   let image = await generateImage(complexPrompt, {resolution: "768x768"});
   ```

   Д. Обработка ошибок:
   ```javascript
   try {
     let image = await generateImage(prom);
     // Обработка результата
   } catch (error) {
     if (error.message.includes("недопустимый промпт")) {
       // Специфичная обработка ошибки промпта
     } else {
       // Общие ошибки
     }
   }
   ```

   Е. Оптимизация производительности:
   - Для быстрых превью используйте 512x512
   - Для финальных результатов - 768x768
   - Избегайте слишком длинных промптов (оптимально до 100 слов)
   - Кэшируйте результаты с помощью seed

5. ТЕХНИЧЕСКИЕ ДЕТАЛИ:
   - Максимальное время генерации: до 60 секунд
   - Поддерживаемые форматы: PNG/JPEG (в data URL)
   - Размер data URL: ~100-500 КБ в зависимости от разрешения
   - Модели: базовая SDXL, оптимизированная для быстрой генерации

6. ОГРАНИЧЕНИЯ:
   - Запрещенный контент: насилие, ненависть, откровенные материалы
   - Максимальная длина промпта: ~1000 символов
   - Частота запросов: не более 5 генераций в минуту
   - Отсутствие поддержки параметров: negative prompts, inpainting

7. ПРАКТИЧЕСКИЕ СОВЕТЫ:
   - Экспериментируйте с разными разрешениями для одного промпта
   - Используйте seed для создания вариаций одного изображения
   - Комбинируйте несколько концепций в одном промпте
   - Добавляйте технические термины: "octane render", "unreal engine"
   - Указывайте художественные стили: "импрессионизм", "сюрреализм"
   - Для портретов добавляйте эмоции: "улыбка", "серьезный взгляд"

8. ИНТЕГРАЦИЯ С ДРУГИМИ ПЛАГИНАМИ:
   ```javascript
   // Генерация описания через generateText
   let description = await generateText("Опиши космическую станцию будущего");
   
   // Генерация изображения по описанию
   let image = await generateImage(description, {resolution: "768x768"});
   
   // Сохранение через uploadPlugin
   let { url } = await uploadPlugin(image);
   ```

9. ДИАГНОСТИКА ПРОБЛЕМ:
   - Если изображение не соответствует ожиданиям:
     1. Упростите промпт
     2. Уточните ключевые элементы
     3. Добавьте стиль
     4. Измените разрешение
     5. Используйте другой seed
   - Если генерация не запускается:
     1. Проверьте длину промпта
     2. Убедитесь в отсутствии запрещенных слов
     3. Проверьте подключение к интернету

10. ПРИМЕРЫ ПРОМПТОВ ДЛЯ ТЕСТИРОВАНИЯ:
    - "Кот в очках читает книгу в уютной библиотеке"
    - "Футуристический город на Марсе, колонии, купола"
    - "Магический лес с светящимися растениями, фэнтези"
    - "Робот пишет картину маслом, студия художника"
    - "Океан с подводным городом, рыбы, свет"

11. ОПТИМАЛЬНЫЙ ПРОЦЕСС РАБОТЫ:
    1. Создайте базовый промпт (10-15 слов)
    2. Сгенерируйте тестовое изображение (512x512)
    3. Уточните детали и стиль
    4. Сгенерируйте финальное изображение (768x768)
    5. Сохраните успешный seed для будущих вариаций

Помните: качество результата напрямую зависит от точности и детальности промпта. Экспериментируйте!
